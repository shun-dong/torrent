# torrent

当前仓库以前期设计为主，先明确世界观、剧情切片和第一周开发边界，再推进原型实现。

## 目录结构

### `documents/`

- `setting.md`
  世界观底稿，记录“清洗”“活雨”“回响”“业”“影隐”“永宁村”等核心设定。

- `storyline.md`
  长线剧情草案，按区域组织主线推进和关键角色出场。

- `gameplay.md`
  系统设计底稿，记录战斗、动作、法术、本能、交互、美术和音乐方向。

- `week1.md`
  第一周开发切片文档，定义本周范围、已确认设定、功能待办和测试待办。

### `data/`

- `room.csv`
  房间/关卡切片表，描述第一周地图中的房间编号、功能、入口出口和关键交互。

- `event.csv`
  事件表，描述新建游戏后的流程、教学、对话、短剧情和雨眠节点。

- `enemy.csv`
  敌人表，只列第一周切片实际会出现的敌人。

- `item.csv`
  物品表，先记录开局装备，后续再扩展其他物品。

- `operation.csv`
  基础操作表，记录第一周原型需要实现的输入与动作。

## 协作原则

- 以 `documents/week1.md` 作为第一周范围基准。
- `data/` 只保留当前切片真正需要的数据。
- 模糊设定先在周计划中拍板，再进入实现。
