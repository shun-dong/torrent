# Week 2 开发切片

目标：在Week 1基础上扩展RPG核心系统，实现物品、法术、商店、首个Boss战，构建更完整的玩法循环。

## 范围

### 地图扩展

- 在S01避难所之后新增2个场景：
  - `S02 避难所深处`：商店区域，NPC交易
  - `B01 回响裂隙`：首个Boss战房间
- 结构保持线性，S01 → S02 → B01
- B01为锁房间设计，进入后触发Boss战，胜利后才可离开

### 已确认设定

- **物品系统**：武器、法术、装备三类，可在存档点更换
- **地图系统**：按M键查看当前区域简图（用第三方素材拼接）
- **灵视值**(san)：用于施放法术，存档点恢复，当前只有基础法术（直线小球）
- **商店**：货币为固定业，可购买武器、法术、装备
- **首个Boss**：`雨核聚合体`，具有锁房间、血条UI、单次刷新特性
- **掉落系统**：Boss击败后掉落固定业
- **对话分支**：NPC对话可选项分支，选择结果可储存

## 本周记录

### Wave 1 已完成

**时间：** 2026-03-20

**完成内容：**
1. **事件系统重构**：
   - 重构 `event.csv` 格式，改为机器可解析的配置驱动格式
   - 新增字段：`room_id`, `trigger_condition`, `trigger_param`, `event_type`, `next_event_id`, `content`
   - 支持事件类型：dialogue, cg, spawn_enemy, tutorial, message, ambience
   - 支持触发条件：first_enter, event_complete, interact_object, enemy_cleared, proximity_npc

2. **创建 RoomBase 基类**：
   - 统一玩家创建/销毁/信号管理逻辑
   - 统一复活逻辑
   - 统一 spawn point 管理
   - 提供事件回调接口：play_cg_event, spawn_enemies, show_dialogue, show_tutorial
   - 8个房间脚本从各自实现改为继承 RoomBase，删除约 400+ 行重复代码

3. **创建 EventManager**：
   - 全局 autoload，负责从 CSV 加载事件配置
   - 触发条件检查与执行器调度
   - 事件完成状态管理
   - 支持事件链（一个事件完成后自动触发下一个）

4. **创建事件执行器系统**（`autoload/event_executors/`）：
   - dialogue_executor.gd - 对话事件
   - cg_executor.gd - CG/过场动画
   - spawn_enemy_executor.gd - 敌人生成
   - tutorial_executor.gd - 教程提示
   - message_executor.gd - 消息显示
   - ambience_executor.gd - 环境效果

5. **room.csv 扩展**：
   - 新增字段：`status_text`（房间状态提示）、`default_spawn`（默认出生点）
   - RoomBase 自动从 CSV 加载房间配置，进一步减少硬编码

**技术债务与后续优化**：
- 8个房间脚本已全部迁移到 RoomBase，代码冗余问题已解决
- 事件系统为 Week 2 的新功能（Boss战、对话分支等）提供了配置驱动的基础架构

### Wave 2A 已完成

**时间：** 2026-03-26

**完成内容：**
1. **room.csv 扩展**：
   - 添加 `coordinate` 字段：房间在地图上的网格坐标（格式：x,y）
   - 添加 `type` 字段：房间类型（start, normal, event, shelter, shop, boss）
   - 添加 `area` 字段：所属区域（village, outskirts）
   - 配置 8 个房间的坐标、类型和区域
   - S01 避难所属于郊区区域（outskirts）

2. **地图系统实现**：
   - 创建 `MapManager` 自动加载脚本，管理房间数据、连接关系和区域分组
   - 创建 `MapUI` 场景和脚本，在右上角显示当前区域地图
   - 使用 ColorRect 方块表示房间，不同类型不同颜色：
     * start（绿色 #4CAF50）
     * normal（灰色 #9E9E9E）
     * event（紫色 #9C27B0）
     * shelter（蓝色 #2196F3）
     * shop（黄色 #FFC107）
     * boss（红色 #F44336）
   - 当前房间白色边框高亮
   - 房间之间显示灰色连线
   - 地图默认开启显示
   - 按 M 键切换地图显示/隐藏

3. **已访问房间机制**：
   - `_visited_rooms` 字典记录已访问房间
   - 地图只显示已访问过的房间
   - 进入房间时自动标记为已访问
   - 连线只显示已访问房间之间的连接

4. **场景切换刷新**：
   - 过图时地图自动刷新显示新区域
   - 不关闭地图，保持开启状态

5. **输入处理**：
   - 在 `GameState` 中添加 `toggle_map` 输入映射（M键）
   - 在 `Main` 中处理地图切换，管理 `MapUI` 实例
   - 在 `RoomBase` 中通知 `MapManager` 当前房间变化

6. **项目配置**：
   - 在 `project.godot` 中添加 `MapManager` 自动加载
   - 更新 `asset-plan.md` 添加地图系统颜色定义

**技术要点：**
- 地图数据在 `MapManager._ready()` 中预计算
- 使用 `Vector2i` 表示房间网格坐标
- 区域分离：只显示当前区域的已访问房间
- 连线双向绘制，避免重复
- `process_mode = PROCESS_MODE_ALWAYS` 确保地图在暂停时仍可处理
