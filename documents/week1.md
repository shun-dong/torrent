# Week 1 开发切片

目标：做出一条可完整游玩的俯视角切片，让玩家从永宁村出发，进入郊区，完成基础战斗，触发一次短剧情，并在避难所雨眠存档。

## 范围

### 地图

- 永宁村：`V01 采薇的家`、`V02 村路`、`V03 村会场`、`V04 村外栅栏`
- 郊区：`G01 郊区入口`、`G02 排水沟`、`G03 废弃农道`、`S01 小型避难所`
- 结构保持单向线性，不做支线、捷径和复杂立体地图
- 当前原型视角采用俯视角，先直接使用 `asserts/third_party/Top-Down_Roguelike_Game_Kit_Pixel_Art/` 中的测试素材

### 已确认设定

- 初始动作只做：四方向移动、互动、短兵攻击、弹反
- 郊区短剧情使用“影隐首次现身”
- 村口由山海的回响引导采薇离村
- 雨眠只做“安全点 + 存档 + 恢复”的最小闭环
- 第一周敌人使用：`雨孢残骸`、`雨虫群`、`湿壳拾荒鼠`
- 第一周不揭示“山海是回响”的真相
- 当前阶段不制作正式美术，角色、敌人、地块、GUI 先使用第三方占位素材

### Wave 4 已完成

**时间：** 2025-03-17

**完成内容：**

1. **死亡复活逻辑修复（高优先级）**：
   - 修复了在避难所存档后死亡导致游戏卡死的 Bug
   - 问题原因：`initialize_arena()` 中玩家实例未正确重建，信号重复连接导致异常
   - 解决方案：所有世界场景 (`v01_home.gd` 到 `s01_shelter.gd`) 统一使用"先断开信号、删除旧玩家、创建新玩家"的复活流程
   - 修正了 `GameState.get_continue_spawn_id()` → `GameState.recent_rainsleep_id` 的使用，确保复活到正确的雨眠点

2. **Debug 模式实现**：
   - 创建 `scenes/debug/debug_manager.gd` 和 `DebugManager.tscn` (CanvasLayer)
   - **F1 - 传送菜单**：显示所有9个房间列表，点击即可传送，支持暂停游戏时操作
   - **F2 - 无敌模式**：玩家不受伤害，自动恢复生命体力
   - **F3 - 清敌**：秒杀当前场景所有敌人
   - **F4 - 快速死亡**：立即触发死亡（用于测试复活逻辑）
   - 移除原计划中的碰撞盒显示功能（实际用途有限）

3. **传送位置修复**：
   - 修复了"无论从哪个方向进入都出现在同一位置"的问题
   - 统一 spawn ID 命名规范：`"V01Entrance"` 表示"来自 V01 的入口"
   - 更新所有场景的 `_spawn_for_id()` 函数，支持双向出生点映射
   - 修复了 V02/V03/V04 等场景的传送门配置

4. **反复跳 Bug 修复**：
   - 问题原因：出生点 (140, 0) 与传送门碰撞范围 (±16) 重叠
   - 解决方案：将 V01 的 V02Spawn 和 V02 的 V03Entrance 从 (140, 0) 移到 (120, 0)
   - 确保所有出生点距离传送门足够远（portal 在 ±150，spawn 在 ±100 或 120）

5. **场景切换流畅度优化**：
   - Portal 冷却时间：1.0 秒 → 0.3 秒 (`area_portal.gd`)
   - 移除 `call_deferred`，直接调用 `_load_arena` 减少延迟

6. **代码质量改进**：
   - 修复 `visible` 参数名 shadowing `CanvasItem.visible` 属性（改为 `is_visible`）
   - 修复 G03 场景敌人信号重复连接问题（添加 `is_connected` 检查）

## 本周总结

Week 1 开发目标已达成。切片包含从永宁村（V01）到小型避难所（S01）的完整线性流程，共计 8 个场景。

**核心功能完成**：
- ✅ 俯视角移动、战斗、弹反系统
- ✅ 三种敌人：雨孢残骸、雨虫群（爆裂）、湿壳拾荒鼠（后撤）
- ✅ 场景切换与双向传送
- ✅ 雨眠存档与死亡复活
- ✅ 两段剧情演出（山海回响、影隐现身）
- ✅ Debug 模式辅助测试

**技术债务与后续优化**：
- 战斗手感可进一步优化（攻击前摇、受击反馈）
- 敌人 AI 行为可更丰富（添加巡逻、警戒范围可视化）
- 剧情演出可添加音效和更多动画
- 需要配置 export_presets.cfg 以支持导出测试

**本周不做（已确认）**：

- 长兵、法术、星图系统
- 业与本能的正式玩法
- 分支对话、商店、装备差异
- 复杂 AI、完整 Boss
- 精致 UI 和正式美术资源

下周可在此基础上扩展：更多敌人种类、首个小 Boss、装备差异化、本能系统原型。
